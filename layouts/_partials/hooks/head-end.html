{{- /* Pre-paint display-option state: read the reader's stored choices from localStorage, set attributes, and emit the filter CSS before the stylesheet paints, so the first frame already matches. Mirrors the theme's own td-preset/td-color-theme bootstrap pattern in head.html. Axes come from params.variants (an ordered slice). The filter rules are GENERATED from the config, not hand-written: for every axis, an active option hides every block on that axis that does not carry the active id or the axis's neutral id. Block ids are whitespace-separated token lists (data-td-variant-id~='...'), so one block can serve several options; an id of `neutral` never hides and is never hidden, and untagged content always renders. Storage-blocked readers keep the config defaults (no filtering). The per-axis config is emitted as JSON (#td-variant-config) for the page-top selector and the Customize form, so both validate values against the configured option ids instead of trusting storage. It also carries the per-axis status phrases (status.specific/status.neutral, {value} = the option label); an axis without them falls back to the axis label ("every " for neutrals). */ -}} {{- $variants := site.Params.variants -}} {{- if reflect.IsSlice $variants -}} {{- /* Validate the config once per build, not once per page. */ -}} {{- if not (site.Store.Get "tdVariantsChecked") -}} {{- site.Store.Set "tdVariantsChecked" true -}} {{- range $variants -}} {{- $axis := printf "%v" (.id | default "") -}} {{- $ids := slice -}} {{- range .options -}}{{- $ids = $ids | append (printf "%v" .id) -}}{{- end -}} {{- if not $axis -}} {{- warnf "params.variants: an axis has no id; it is skipped" -}} {{- else if not $ids -}} {{- warnf "params.variants: axis %q has no options; it is skipped" $axis -}} {{- else -}} {{- if not (in $ids (printf "%v" .neutral)) -}} {{- warnf "params.variants: axis %q has no option matching its neutral id %q" $axis .neutral -}} {{- end -}} {{- if not (in $ids (printf "%v" .default)) -}} {{- warnf "params.variants: axis %q default %q is not one of its option ids" $axis .default -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* Chat assistant styles (static/css/chat.css). relLangURL because GitHub Pages serves this site under /CAI-Field-Manual-Migration-2-3/: a root-absolute href would 404 there. */ -}} {{- /* "Feed it to my AI Agent" modal styles (static/css/agent-setup.css).
